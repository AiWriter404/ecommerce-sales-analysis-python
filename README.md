# E-Commerce Sales Analysis using Python

## Project Overview

This project analyzes an e-commerce sales dataset containing 5,000 transactions. The goal is to uncover business insights, identify top-performing product categories, and evaluate regional sales performance.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dataset Information

* Total Records: 5,000
* Total Features: 12
* Missing Values: 0
* Duplicate Records: 0

## Business Questions Answered

1. What is the total revenue generated?
2. Which product category generates the highest revenue?
3. Which region performs best in terms of sales?
4. How is revenue distributed across categories and regions?
5. What business insights can be derived from the data?

## Key Findings

* Total Revenue: $5.1M+
* Electronics generated the highest revenue.
* Clothing was the second-best performing category.
* West region produced the highest revenue.
* Revenue distribution across regions was relatively balanced.
